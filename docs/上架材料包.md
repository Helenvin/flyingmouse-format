## 中文短描述

鼠鼠主题的本地离线文件格式转换工具，支持图片、文档、表格、演示文稿、PDF、字幕、音视频、OCR 与批量处理，并可记住常用目标格式和保存目录。

## English short description

A mouse-themed offline file converter for images, documents, spreadsheets, presentations, PDFs, subtitles, audio, video, OCR, and batch workflows, with remembered format and save preferences.

## 功能要点

- 鼠鼠会根据上传、识别、批量、OCR、成功和失败状态切换动作。
- 使用本地 FFmpeg、LibreOffice、Poppler、Tesseract、Sharp 等引擎处理文件。
- 支持批量队列、逐文件结果、单独保存和保存全部。
- 按源扩展名分别记忆目标格式；用户改选后自动更新默认值。
- 记住上次保存目录。
- 支持简体中文和 English，并记住语言选择。
- 文件在本机处理，不上传到云端转换服务。
- PDF → Excel 提供智能表格提取，并对扫描件、复杂表头和合并单元格明确提示适用边界。
- 支持 SRT、VTT、ASS、SSA 字幕互转及 TXT 导出，对样式、定位和精度损失提供提示。
- 支持 PDF 转 Markdown，以及图片通过 OCR 转可编辑 DOCX / Markdown；文字会重排，不承诺还原原稿插图和复杂版式。
- 多页 TIFF 逐页 OCR；对旋转、倾斜和识别质量不足提供校正、重试或复核提示。
- Office 引擎在后台准备，界面先显示；准备期间可使用图片、文本和字幕转换。
- 提供完整版和轻量版；轻量版保留普通转换与文字 OCR，高级扫描表格需要完整版。
- 高级 PDF 结构识别有页数与像素预算；普通转换受引擎能力和机器内存约束，具体能力以运行时为准。

## 安装说明

1. 下载并运行安装包。
2. 按向导选择安装目录。
3. 从桌面或开始菜单启动 FlyingMouse Format。
4. 拖入文件，选择目标格式，转换后选择保存位置。

本地 0.7.1 安装包当前未签名，Windows SmartScreen 可能提示未知发布者；交付时应同时提供对应 SHA-256。安装器的安装与卸载流程尚未实测，不能以包完整性检查代替。尚未上传 0.7.1 商店候选包，待完成 [微软商店上架清单](微软商店上架清单.md) 后再记录外部状态。
